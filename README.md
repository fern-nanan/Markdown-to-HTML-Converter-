# Markdown to HTML Converter

A fast, real-time Markdown to HTML converter web application with a vibrant pink-themed user interface.

## Features

- **Real-Time Preview:** View rendered HTML output instantly while typing Markdown.
- **Raw HTML Export:** Readily access and copy generated HTML code.
- **Custom Pink Theme:** Styled interface featuring custom scrollbars and dark pink accents.
- **Responsive Design:** Optimized layout for desktop and mobile screens.

## Project Structure

```text
├── index.html     # Structural markup and inline CSS styling
├── styles.css     # External stylesheets (optional override)
└── script.js      # Core logic for real-time Markdown conversion

```

## Getting Started

1. Download or clone this repository.
2. Open `index.html` in any modern web browser.
3. Type Markdown text into the **Markdown Input** box to view output instantly.
